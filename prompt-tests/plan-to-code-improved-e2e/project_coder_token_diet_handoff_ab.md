Goal: prove that **inlining engine/type contracts into coder task-handoffs** cuts coder-subagent token spend, by running an **A/B benchmark and diffing the two runs' telemetry**.

**Root cause of the original waste (STEERABLE-DAG-2.3, rad-orc session `b263a697`):** coders were ~88% of a ~79M-token session; **96.5% cache-read**. Archetype coder grew context 9K→318K over ~69 turns; 59 Reads across 51 files to edit 5 — it over-read because the handoff *named* engine contracts but **inlined none**, so it reconstructed them from source. Cost model = **turns × context-size-per-turn**, paid as cache-read.

## Round 1 — RAN 2026-07-10 (result: real but modest, NOT the hoped 2.5×)
- **Arm A ORIGINAL** (contracts named): session `3288e8c7-0279-48fc-8ece-7df1552358bc`, coder agent `aa27ad20fed7dc984`.
- **Arm B IMPROVED** (contracts inlined): session `a4ca8e35-629e-49d7-961c-80204003e0cb`, coder agent `af7dd3253281197bd`.
- **Coder subagent A→B:** cache-read **14.94M→10.83M (−27.5%)**; turns **99→69 (−30%)**; output 110K→74.6K (−32%); total 15.33M→11.17M (−27%).

**Why it fell short of the 2.5× goal (the diagnosis is the real finding):** the intended *mechanism didn't fire.* Distinct files read **54→50 (−7%)** and peak context **281K→265K (−6%)** — Arm B *still swept ~18 files under `lib/graph-engine/**`* even though the improved handoff **explicitly said "do NOT read the engine's implementation under `lib/graph-engine`"** (the in-task prohibition was **overridden ~18×**). Mean context/turn actually *rose* 154K→161K (bigger handoff = per-turn tax). The entire saving came from **parallel tool batching, not read-avoidance**: Arm A issued every tool in its own round-trip (**1.00 tools/turn**, zero batching); Arm B packed the same ~96 calls into 69 turns (**1.39 tools/turn**, 18 multi-tool turns). Fewer round-trips × ~same per-turn context = the 27%.

**Why the coder still read engine source (from its own narration, agent `af7dd325`):** the inlined contract was **not compile-complete** — it gave *shapes* but not (a) exact importable symbol names + their module, or (b) ~15 transitively-referenced types (`NodeId`,`DagNode`,`DagEdge`,`NodeChange`,`EdgeChange`,`NodeStatus`,`NodeSpec`,`MutationSpec`,`PreviewCone`,…). `tsc` can't be satisfied by a paraphrase → it opened `index.ts`+model files to confirm names ("double check `Expansion`/`NodeSpec` import path spelling"). A prohibition can't beat a compile requirement. (A few inlined shapes were also subtly wrong — `captureDeltas`→`captureDelta` — but that helper is graph-service driver code, a sanctioned read.)
